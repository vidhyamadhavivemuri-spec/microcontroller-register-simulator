# Microcontroller Register Simulator

## Overview

The **Microcontroller Register Simulator** is an educational Embedded C project designed to demonstrate how microcontrollers interact with hardware through memory-mapped registers.

The project simulates fundamental peripherals such as GPIO, UART, Timers, and Interrupts without requiring physical hardware.

## Objectives

- Understand register-level programming
- Learn memory-mapped I/O
- Practice Embedded C programming
- Simulate peripheral behavior
- Build a modular software architecture

## Planned Modules

- Register Module
- GPIO Module
- UART Module
- Timer Module
- Interrupt Module
